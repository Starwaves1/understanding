### svg — a hand-drawn illustration in the card
`{"op":"svg","viewBox":"0 0 400 220","markup":"<path d='M40 150 L360 150' stroke='#2b2a27' stroke-width='3' fill='none'/>...","caption":"Side view"}`
Use for 2D pictures of physical things: cross-sections, cutaways, side views, schematics, layouts. Draw like a technical illustrator: real proportions, the actual outline of the object, internal parts drawn in place, and labels INSIDE the svg as text with thin leader lines to the part they name. A "detailed diagram" deserves 30–80 elements; use viewBox "0 0 600 300" for wide objects (the card widens). Simple shapes only: path, line, rect, circle, ellipse, polygon, polyline, text (font-size ≥ 11). Single quotes inside markup. Stroke #2b2a27; fills from #3d7fd9 #e8833a #3a9d5d #f0b429 #8a5cd6 #b8bcc4 #e6f0fc #fdeede. Strokes animate as if drawn, in document order: outline first, then internals, then labels. When the user asks to be SHOWN how to do something physical, sketch the key moment, not only steps.
